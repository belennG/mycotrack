# MycoTrack Frontend

React + TypeScript + Vite frontend for the MycoTrack mushroom cultivation management app.

## Prerequisites

- Node.js (v18+)
- npm

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
Starts Vite dev server with Hot Module Replacement (HMR).
```bash
npm run dev
```

### 3. Build for Production
Compiles TypeScript and bundles production static assets into `/dist`.
```bash
npm run build
```

### 4. Preview Production Build
Locally serve the production build generated by `npm run build`.
```bash
npm run preview
```

### 5. Run Tests
Executes the test suite using Vitest.
```bash
npm run test
```
